Hand3R HOI4D split used for training and paper evaluation
==========================================================

Expected dataset root:
  <HOI4D_PROCESSED_ROOT>

Split unit:
  (H, C, S), encoded as H{subject}_C{category}_S{scene}.
  All clips/takes belonging to one (H, C, S) group stay in the same split.

Split construction:
  - random seed: 42
  - held-out ratio: 0.25, stratified by category C
  - 143 training scenes / 1271 clip directories
  - 42 held-out scenes / 411 clip directories

Important paper-evaluation detail:
  The results reported in Table II use the directory named `val2`, a
  300-clip subset of the held-out split. It covers 39 of the 42 held-out
  scenes. Of those 300 clips, 298 pass the evaluator's validity checks and
  contribute to the reported Hand3R aggregate. Thus, the paper's "HOI4D
  test set" means this custom scene-disjoint held-out split/subset; it is
  not the official hidden HOI4D test server split.
